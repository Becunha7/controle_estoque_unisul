✅ FUNCIONALIDADES IMPLEMENTADAS

1. CRUD PRODUTO
   ✓ Cadastrar novo produto
   ✓ Listar produtos (alfabético)
   ✓ Atualizar dados do produto
   ✓ Excluir produto
   ✓ Validação de quantidade em estoque

2. CRUD CATEGORIA
   ✓ Cadastrar categoria (com tamanho e embalagem)
   ✓ Listar categorias
   ✓ Atualizar categoria
   ✓ Excluir categoria
   ✓ Enums: Tamanhos (PEQUENO, MÉDIO, GRANDE)
   ✓ Enums: Embalagens (LATA, VIDRO, PLÁSTICO)

3. CRUD MOVIMENTAÇÃO
   ✓ Registrar entrada de produtos
   ✓ Registrar saída de produtos
   ✓ Histórico de movimentações
   ✓ Transações ACID (rollback em caso de erro)
   ✓ Validação de quantidade antes de saída

4. RELATÓRIOS (5 TIPOS) ⭐
   
   📊 Relatório 1: Lista de Preços
      • Produtos em ordem alfabética
      • Preço unitário, unidade e categoria
      • Formato: R$ (moeda brasileira)

   📊 Relatório 2: Balanço Físico/Financeiro
      • Quantidade em estoque por produto
      • Valor total por produto (Qtd × Preço)
      • Total geral do estoque
      • Pop-up com valor total consolidado

   📊 Relatório 3: Produtos Abaixo do Mínimo
      • Lista produtos com estoque < mínimo
      • Nome, quantidade mínima, estoque atual, categoria
      • Alerta para reposição

   📊 Relatório 4: Quantidade de Produtos por Categoria
      • Contagem de produtos por categoria
      • Ordenação alfabética
      • Análise de distribuição

   📊 Relatório 5: Produtos Mais Movimentados
      • Produto com maior entrada
      • Produto com maior saída
      • Análise de movimentação
